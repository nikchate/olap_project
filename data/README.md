## 1. Концепция и цели аналитики
Используется базовый sample курса (Розничные продажи).

**Что буду исследовать и считать (бизнес-вопросы):**
- Динамика общей выручки по месяцам и дням.
- Топ-5 самых продаваемых товаров по категориям.
- Сравнение выручки между разными магазинами и городами.
- Средний чек покупки.

**Ключевые метрики:**
- Выручка: `sum(amount)`
- Количество проданных единиц: `sum(quantity)`
- Средний чек: `sum(amount) / count(distinct order_id)`

## 2. Исходные данные (data/raw/)
В папке `data/raw/` находятся исходные таблицы:
- `fact_sales.csv` — факты продаж (order_id, date_id, store_id, product_id, quantity, amount)
- `dim_product.csv` — справочник товаров (product_id, product_name, category, price)
- `dim_store.csv` — справочник магазинов (store_id, store_name, city)
- `dim_date.csv` — календарный справочник (date_id, year, month, day)
